# Frontend

Web 前端知识库。笔记按技术分类放在 `docs/`，可运行案例在 `examples/`，完整旧项目在 `practice/legacy/`。

本地预览：

```bash
npm install
npm run docs:dev
```

开发地址是 `http://localhost:5173/frontend/`。`npm run docs:build` 生成静态站点，GitHub Actions 会把它发布到 GitHub Pages。

每个技术点按四块学习：输入与输出、案例、测试、实战。分类首页写了已迁入的笔记和案例路径。费曼学习法用来在学完后自己讲一遍，不决定目录。

内容来自另外 9 个仓库的一次性迁入，对照表在 `docs/sources.md`。之后只改这个仓库。
