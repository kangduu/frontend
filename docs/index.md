## 每一类怎么学

1. **输入与输出**：这个技术接收什么，产出什么。
2. **案例**：`examples/` 里能单独跑的最小例子。
3. **测试**：该例子自带的测试命令。
4. **实战**：`practice/legacy/` 里已经做过的完整项目。

学完一个点之后，用自己的话讲清楚输入怎样变成输出，用来检查是否掌握。
