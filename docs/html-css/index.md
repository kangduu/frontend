# HTML 与 CSS

文档树、选择器、盒模型、布局，以及 Sass、Less。Tailwind 还没有迁入笔记。

## 输入与输出

选择器的输入是一组规则，输出是每个元素最终生效的声明。Sass 和 Less 的输入是带变量和嵌套的样式文本，输出是普通 CSS。
