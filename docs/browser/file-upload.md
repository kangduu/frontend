# file-upload

Test files, large files, multi-file uploads, and folder uploads

## Quick Start

1. Clone the repository
2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
npm run start
```

4. Open the browser and navigate to `http://localhost:3000`

## Features

- [x] Single file upload
- [x] Multi file upload
- [x] Folder upload
- [x] Large file upload
- [x] Chunk upload
- [x] File verification
