# React

组件把数据变成文档树。Ant Design 和 Umi 是这套写法上的库和应用框架。

## 输入与输出

组件的输入是 props 和 state，输出是下一次要渲染的树。Ant Design 的输入是它规定的 props，输出是已经设计过的界面。Umi 的输入是约定式目录和配置，输出是带路由的应用构建结果。
