# Node.js

运行时、文件、HTTP 和小型 API。8 周安排见 [路线图](./roadmap)，主题顺序见 [原文概览](./README)。

## 输入与输出

模块的输入是文件路径，输出是导出的值。HTTP 服务的输入是请求，输出是响应。

## 案例与测试

`examples/nodejs/` 下每个目录是一个案例，包括 `hello-node`、`notes-api`、`todo-express`、`auth-api`、`file-upload`、`duk-cli`、`ssr`。有 `package.json` 的目录按其中的脚本启动。

## 实战

`examples/nodejs/message-board` 和 `examples/nodejs/auth-api` 是带注册或留言的小服务。上传案例同时属于 [浏览器 / 文件上传](/browser/file-upload)。
